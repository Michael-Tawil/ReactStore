# 🛒 React Store

A clean, responsive e-commerce store built with React — designed to showcase my ability to develop modern frontend applications with routing, authentication, and state management.

---

## 🚀 Project Goal

This project simulates a simple e-commerce experience with product browsing, cart management, and login protection. It was built to demonstrate my ability to:

- Manage global state with React
- Implement real-world features like authentication and cart logic
- Build responsive, user-friendly UIs with Tailwind CSS

---

## ✅ Core Features

- 🛍️ Add to Cart / Remove from Cart
- ➕ Quantity management
- 🔐 Login flow (mock auth)
- 🚫 Protected Routes (Cart, Checkout)
- 💾 LocalStorage persistence (Cart & Auth)
- 🧠 Global Cart State via React Context API
- 🔔 Toast notifications for feedback
- 📱 Fully responsive design
- ⚠️ 404 page and routing fallback

---

## 🛠️ Tech Stack

- React
- React Router DOM
- Tailwind CSS
- React Toastify
- React Context API
